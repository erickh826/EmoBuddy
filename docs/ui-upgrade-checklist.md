# 外觀升級項目清單

以下列出目前遊戲中可視覺升級的所有元件與區域，按優先順序排列。

---

## 1. 歡迎畫面 (WelcomeScreen)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 標題文字 | 純文字「情緒碎片」 | 加入手繪風格標題字體或 Logo |
| 玩家角色預覽 | 靜態圓形 + 表情符號 | 動畫角色（眨眼、呼吸、浮動） |
| 背景 | 純白 | 漸層背景或插畫場景（天空、草地） |
| 開始按鈕 | 標準 shadcn Button | 圓潤大按鈕 + 懸浮陰影 + 點擊回饋動畫 |

---

## 2. 關卡介紹畫面 (LevelIntro)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 關卡名稱 | 純文字 | 加入情緒主題色背景卡片 |
| 目標圖示 | 單色圓形 + Lucide icon | 動畫圖示（碎片旋轉、夥伴揮手） |
| 背景 | 純白 | 關卡主題背景（花園有花、森林有樹） |
| 開始按鈕 | 標準按鈕 | 脈衝動畫吸引點擊 |

---

## 3. 遊戲畫面 (GameBoard)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 地圖格子 | 灰白方塊 | 主題材質（草地、泥土、石板） |
| 障礙物 | 灰色方塊 | 主題障礙物（石頭、樹幹、柵欄） |
| 玩家角色 | 橙色圓形 + 表情符號 | 自定義角色精靈（可換裝） |
| 碎片 | 單色圓形 + icon | 發光動畫碎片（旋轉、閃爍） |
| NPC 夥伴 | 綠色圓形 + icon | 角色精靈 + 待機動畫 |
| 完成效果 | 黃色 ping 動畫 | 粒子爆發 + 星星飛散 |
| 關卡標題列 | 純文字 | 主題色標題條 + 進度指示器 |

---

## 4. 方向控制盤 (DirectionPad)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 按鈕外觀 | 灰色方塊 + 箭頭 | 圓潤大按鈕 + 主題色 |
| 按下回饋 | 顏色變深 | 縮放動畫 + 音效 + 震動（手機） |
| 整體布局 | 十字形 | 可選搖桿模式（虛擬搖桿） |

---

## 5. 現實世界任務彈窗 (RealWorldTask)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 彈窗背景 | 白色卡片 | 毛玻璃/半透明 + 模糊背景 |
| 任務圖示 | Lucide icon | 手繪風格插畫圖示 |
| 選擇按鈕 | 標準 outline | 大圓角卡片 + 懸浮效果 |
| 已選狀態 | 綠色填充 | 勾選動畫 + 邊框發光 |
| 完成按鈕 | 標準按鈕 | 脈衝動畫 + 彩虹漸層 |

---

## 6. 家長確認畫面 (ParentUnlock)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 鎖定圖示 | Lucide Lock | 動畫鎖（搖晃、開鎖動畫） |
| 進度條 | 底部綠色條 | 圓形環繞進度或填充動畫 |
| 提示文字 | 純文字 | 加入插畫提示（家長手勢圖示） |
| 成功效果 | 無 | 解鎖動畫 + 音效 + 彩帶 |

---

## 7. 關卡完成畫面 (LevelComplete)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 星星圖示 | 靜態 Star icon | 旋轉發光星星 + 粒子效果 |
| 完成訊息 | 純文字 | 打字機效果逐字顯示 |
| 背景 | 純白 | 慶祝背景（彩紙、氣球） |
| 下一關按鈕 | 標準按鈕 | 閃爍箭頭 + 彈跳動畫 |

---

## 8. 獎狀畫面 (Certificate)

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 獎狀邊框 | 簡單圓角 | 裝飾性邊框（花紋、絲帶） |
| 獎盃圖示 | 靜態 Trophy | 3D 風格或動畫獎盃 |
| 背景 | 白色 | 漸層或紙張質感 |
| 關卡列表 | 純文字 | 圖示 + 進度條 + 完成印章 |
| 下載按鈕 | 標準 outline | 大圓角 + 下載動畫 |
| 整體排版 | 簡單列表 | 證書風格排版（居中、對稱） |

---

## 9. 整體 UI 主題

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 配色 | 單色調（slate + 主題色） | 每關獨立主題色板 |
| 字體 | 系統預設 | 手寫風格或圓潤字體（適合兒童） |
| 過場動畫 | 無 | 頁面切換滑動/淡入淡出 |
| 音效視覺化 | 無 | 移動時腳步塵埃、收集時光環 |
| 載入畫面 | 無 | 可愛載入動畫（角色走路） |

---

## 10. 響應式與觸控優化

| 項目 | 目前狀態 | 建議升級 |
|------|----------|----------|
| 手機布局 | 垂直堆疊 | 橫屏/直屏自適應 |
| 按鈕大小 | 標準 | 加大至 48px+ 適合小手 |
| 觸控回饋 | 顏色變化 | 震動 API + 聲音 + 動畫 |
| 手勢支援 | 無 | 滑動移動（swipe） |

---

## 優先級建議

1. **高優先**：玩家角色精靈、碎片/NPC 動畫、方向盤觸控回饋
2. **中優先**：關卡主題背景、過場動畫、字體升級
3. **低優先**：獎狀裝飾、載入畫面、手勢支援
