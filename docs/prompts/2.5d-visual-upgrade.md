# feature/2.5d-visual-upgrade — 实施提示 & QA 提示 & AI 生图提示

---

## Part A: 实施提示 (Implementation Prompt)

### 任务目标
将 EmoBuddy 游戏的视觉从纯色方块升级为 **Top-down 2.5D Bomberman 风格**，建立正式 Theme System，支持三关独立主题。

### 技术约束
- 框架：React + TypeScript + Vite
- 渲染：DOM + CSS Grid（**不使用** Canvas/Phaser）
- 状态管理：useReducer
- 样式：Tailwind CSS + shadcn/ui
- **ASD 友善**：无闪烁动画、低饱和度、支持 `prefers-reduced-motion`

### 实施清单

#### Step 1: 建立 ThemeConfig 类型与数据
- 文件：`src/types.ts` 或新建 `src/themes/types.ts`
- 定义 `ThemeConfig` 接口：
```typescript
interface ThemeConfig {
  id: string;              // e.g. "happy-garden"
  className: string;       // CSS class name for theme
  floorTexture: string;    // URL or path to floor tile
  wallTexture: string;     // URL or path to wall tile
  borderTexture: string;   // URL or path to border tile
  shardTexture: string;    // URL or path to shard sprite
  npcTexture?: string;     // URL or path to NPC sprite
  backgroundColor: string; // fallback color
  accentColor: string;     // UI accent
}
```

- 文件：新建 `src/themes/index.ts`
- 定义三套主题数据：
  - `happyGardenTheme` — 开心花園（花朵、暖色调）
  - `calmForestTheme` — 平靜森林（树木、绿色调）
  - `braveHillsTheme` — 勇敢山丘（岩石、暖橙色调）

- 文件：`src/levels.ts`
- 在 `LevelConfig` 中新增 `theme: ThemeConfig` 字段
- 每个关卡关联对应主题

#### Step 2: 替换地图素材 (Floor / Wall / Border)
- 文件：`src/components/GameBoard.tsx`
- 改造 `GameBoard` 组件：
  - 根据当前关卡的 `ThemeConfig` 动态切换 tile 图片
  - Floor 格子（grid=0）：使用 `floorTexture` 背景图
  - Wall 格子（grid=1）：使用 `wallTexture` 背景图
  - 地图边界：使用 `borderTexture` 边框装饰
- 使用 CSS `background-image` + `background-size: cover`
- 保持 Grid cell 尺寸响应式（`min(88vw, 560px)` / gridSize）

#### Step 3: 替换 Player 为四方向 Sprite
- 文件：`src/components/GameBoard.tsx`（或新建 Player 子组件）
- 根据 `Direction` 状态切换显示对应方向的 Sprite：
  - `up` → player-up sprite
  - `down` → player-down sprite
  - `left` → player-left sprite
  - `right` → player-right sprite
- Player Sprite 规格：
  - Source size: 256×256
  - 使用 `object-fit: contain` + CSS `transform` 定位
  - 移动时添加平滑 CSS `transition`（~150ms）
- 保持 ASD 友善：无呼吸/眨眼循环动画（或仅在 `prefers-reduced-motion: no-preference` 时启用极轻微 idle 动画）

#### Step 4: 替换碎片和 NPC 素材
- Shard（碎片）：使用 `shardTexture` 替代当前纯色圆形
  - 可添加轻微 CSS `filter: drop-shadow()` 发光效果
  - 仅在 `reducedMotion === false` 时添加极慢速旋转（~8s 一圈）
- NPC（第三关）：使用 `npcTexture` 替代当前绿色圆形
  - 可添加静态朝向（面朝玩家初始方向）

#### Step 5: 建立 CSS 主题变量系统
- 文件：`src/themes/themes.css`
- 使用 CSS 自定义属性实现主题切换：
```css
.theme-happy-garden {
  --theme-bg: #fef9e7;
  --theme-accent: #f5a623;
  --theme-text: #5d4037;
}
.theme-calm-forest {
  --theme-bg: #e8f5e9;
  --theme-accent: #4caf50;
  --theme-text: #2e3b2e;
}
.theme-brave-hills {
  --theme-bg: #fff3e0;
  --theme-accent: #e67e22;
  --theme-text: #4e342e;
}
```
- 在 `App` 或 `GameBoard` 的 wrapper div 上动态设置 `className`

#### Step 6: 更新关卡介绍与完成画面
- `LevelIntro`：使用主题色背景卡片 + 主题图
- `LevelComplete`：使用主题色庆祝效果
- `WelcomeScreen`：选择默认/通用主题

### 验收标准
- [ ] 三关各自显示不同的 tile 主题（地板、障碍物、边框）
- [ ] Player 根据移动方向显示正确朝向 Sprite
- [ ] 主题色贯穿 LevelIntro → GameBoard → LevelComplete
- [ ] 地图边界有砖块/石墙视觉
- [ ] 碎片和 NPC 使用 Sprite 替代纯色圆形
- [ ] ASD 友善：无闪烁、`prefers-reduced-motion` 下关闭所有装饰动画
- [ ] Desktop + Mobile Safari/Chrome 正常渲染
- [ ] 切换关卡时主题正确切换，无残留
